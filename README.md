# 海鸥农场场部 2m×2m 仿真展示沙盘三维方案呈现系统

## 项目概况
- **地理区位**：广东省湛江市徐闻县曲界镇（著名的“菠萝的海”核心区）· 国营海鸥农场场部
- **历史年代**：1952 - 1980 年代农垦拓荒时期历史风貌复原
- **实体沙盘规格**：
  - 外尺寸：2000mm × 2000mm × 1000mm
  - 有效地形展示区：1900mm × 1900mm（预留外边框 50mm）
  - 底座结构：40×40 镀锌方管承重钢架 + 18mm 阻燃多层木工板台面
  - 防尘罩：2000×2000mm 高透 8mm~10mm 一体亚克力防尘罩
  - 底面：高精卫星遥感影像 UV 平板喷绘
  - 建筑：SLA 工业级光敏树脂 3D 打印（约 4.5~5.5kg 耗材）+ 手工做旧上色
  - 智能多媒体：微波雷达感应 + 情绪价值温情配乐解说音频
- **总预算控制**：严格控制在 1.5 ～ 1.8 万元人民币内

## 在线三维演示
- 基于 WebGL / Three.js 构建的高保真 3D 交互沙盘
- 支持 360° 旋转、缩放、剖切透视、历史建筑铭牌交互与语音模拟
